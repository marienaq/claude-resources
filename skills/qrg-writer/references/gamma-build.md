# Visual Patterns (Gamma Build)

How the QRG renders in Gamma. Load when preparing the markdown for Gamma or reviewing the rendered resource.

## Page Setup

- Built in Gamma as a **document** (not presentation), using the "pageless" or "fluid" card dimension
- **Card width:** Large
- **Font size:** Small
- Each activity is a distinct page/section
- Clean, corporate aesthetic matching ABA brand

## Card System

- **Gray background cards** for callouts (Key Mental Shift, How to Use This Guide)
- **Colored-header cards** for approach steps (collapsible in web, expanded in PDF)
- **Two-column cards** for Limitations + Refining Your Results
- **Grid cards** for Pro Tips (2-column numbered grid)

## Color System

| Element | Color | Use |
|---------|-------|-----|
| Series label | Teal (#008095) | "Group AI Resource" on cover |
| Section headings | Dark gray | Activity titles |
| Approach card headers | Rotating (teal, blue, maroon) | Step cards, with maroon for critical/final steps |
| Key Mental Shift card | Gray background | Callout |
| Limitation bullets | Maroon (#870833) | Red dots |
| Refining question bubbles | Teal (#008095) | Speech bubble styling |
| Pro Tip numbers | Brand color rotation | Circled numbers |
| Prompt annotations | Blue/Purple/Pink/Green | Component labels |

## Approach Diagrams

- Uses the **Bubbles smart diagram** in Gamma
- Numbered steps: "1. [Label]", "2. [Label]", etc.
- Each bubble uses a **different color** from the brand palette
- In markdown: write as a numbered list separated by pipes (e.g., `1. Lock the scope | 2. Extract the facts | 3. Organize for your needs`)

## Smart Layout and Diagram Titles

- Always **h4 bold** for smart layout titles and smart diagram titles
- Title font color should match the corresponding bubble/element color
