# Opening, Q&A, Break, and Closing Patterns

The non-activity sections of a workshop: how to open the room, run Q&A windows, place breaks, and close. Load this when writing the opening, any Q&A window, a break/transition, or the closing.

## Opening Patterns

The opening sets the room before the first activity. It establishes the frame, builds early trust, and previews the structure.

### Standard Opening (Declarative)

Use when the audience is generally open to AI and doesn't need significant trust-building.

| Segment | Typical Time | Purpose |
|---|---|---|
| Leadership intro | 1 min | Signal organizational investment. Set the "why." |
| Frame and set expectations | 2-3 min | Name what today is and isn't. |
| Structure overview | 2 min | Activities, pattern, participation norms. |
| **Total** | **~5-6 min** | |

### Demo-Led Opening (Experiential)

Use when the audience is nervous, skeptical, or not bought in. The demo does the framing work experientially: they see what AI does before you tell them the structure.

| Segment | Typical Time | Purpose |
|---|---|---|
| Leadership intro | 1 min | Signal organizational investment. |
| How the workshop was designed | 1 min | Break the "sell job" expectation. Acknowledge the room. |
| Our Purpose | 2 min | State the goal. Clear, direct, about them. "Not for craft" framing. |
| Warm-up demo + land the pattern | 4 min | Visual proof of concept. Name the pattern throughline. |
| How We'll Work | 2 min | Activities, consistent pattern, participation norms. |
| **Total** | **~10 min** | |

**When to use the demo-led variant:**
- Team is nervous/skeptical about AI
- First workshop with this team
- Manager has flagged trust or fear-of-replacement concerns
- Audience needs to see before they believe

**Demo selection criteria:**
- Fast (under 2 minutes live)
- Visual and immediately understandable
- Clearly not about their core work (universal corporate overhead)
- Demonstrates the "input → task → output" pattern

## Q&A Sections

Q&A windows are optional. Include them when the manager has requested dedicated question time, or when the audience needs space to process between activities.

**Standard Q&A pattern:**

**Open it up (~1 min):**
- "Before we move on, let's take a few minutes. You just tried something new. What questions came up?"
- "You can unmute, or drop a question in the chat, whatever's more comfortable."

**If questions come (~5-7 min):**
- Answer conversationally, not as a lecture. Keep responses short.
- If a question is about a later activity, name it: "Great question. We're actually going to get into that in the next activity."
- If a question is about AI fear/trust/job impact, don't deflect. Answer honestly and connect it back to the frame.

**If the room is quiet:**
- Virtual rooms are often quiet for Q&A, especially early. Don't panic. Have prompts ready:
  - "What surprised you about the output? Anything you didn't expect?"
  - "Was there a moment where it felt useful? A moment where it didn't?"
  - "Anything you're skeptical about? Something that seems too good to be true?"
- If still quiet, share a facilitator observation from the Try segment.

**Wrap and transition (~2 min):**
- Briefly acknowledge themes: "Good questions. A few themes I'm picking up: [name 1-2]."
- Bridge to next section.

## Break + Transition

Include breaks in workshops over 90 minutes. Typical placement: after the second of three activities (roughly halfway).

**Break (~3 min):**
- "We're halfway through. Take 3 minutes: stretch, refill your coffee, step away from the screen. We'll start back up at [time]."
- Put a timer or "back at X:XX" on screen.

**Transition (~2 min):**
- Acknowledge what they've done so far
- Name the shift: if the next activity introduces a new type of task (e.g., from organizing to evaluating), call that out explicitly.

## Closing Pattern

The closing bridges the workshop to the next day. It should reinforce the frame, give them something concrete, and leave them feeling supported.

| Segment | Typical Time | Purpose |
|---|---|---|
| Recap | 2 min | Reinforce the throughline. Name what they did, not what AI did. |
| Micro-commitment | 4 min | Each person names one specific task they'll try before a deadline. |
| What's next | 4-5 min | Follow-up sessions, next workshop, where to get help, close. |
| **Total** | **~10-11 min** | |

**Recap:**
- Tie the session together. Name all activities covered.
- Repeat the pattern throughline.
- Reinforce the frame: "None of this replaces what you do. All of it is designed to get you to that work faster."

**Micro-commitment:**
- Prompt: "Between now and [deadline], try one of the approaches we covered today on something real. Not a big project. Something small, something you'd normally spend 20-30 minutes on."
- "In the chat, name the specific task."
- Wait. Give them time. Virtual rooms need silence to type.
- Read and acknowledge. Don't evaluate. Look for specificity.
- If vague, push gently: "Can anyone get more specific? What's the actual email or meeting or brief?"

**What's next:**
- AI Champion follow-up session (reinforces internal support)
- Next workshop preview (just enough to know there's a roadmap)
- Where to get help ("reach out to [AI Champion]")
- Close with appreciation + handoff to leadership
