# Proposal Skill Quality Checklist

Run the relevant section before presenting any artifact to the user. Voice and style rules (including dash rules): `/writing-guide.md` at the repo root is canonical.

**Brief (Mode 1)**
- [ ] Every theme has direct quotes
- [ ] Lighthouse Client check is explicit
- [ ] Service-tier reactions reference what was said
- [ ] Stakeholder Validation Agenda exists
- [ ] Open questions are concrete and chase-able

**Validation (Mode 2)**
- [ ] Validation has happened OR user has explicitly chosen to skip at risk
- [ ] Brief has been updated with stakeholder responses
- [ ] Budget range is confirmed (or explicitly TBD)

**Packages (Mode 3)**
- [ ] Phase 1 has a 3-month value-proof point
- [ ] Composition was derived from brief, not defaulted
- [ ] Pricing reflects partnership realities (rev shares, facilitator costs)
- [ ] Lighthouse Client + first engagement = introductory pricing considered

**Pitch (Mode 4)**
- [ ] All 6 KY elements are present (Narrative, Alignment, Proof, Process, Offer, Timing)
- [ ] Narrative mirrors prospect's pain in their words
- [ ] Alignment slide pauses for explicit conceptual agreement
- [ ] Proof slide is tight (number + credential + logos), no per-engagement detail
- [ ] Process shows production rigor, not session-arc preview
- [ ] Offer has two options with recommended one emphasized
- [ ] Timing closes with a question
- [ ] Subtitles iterated to near-perfect; style follows `/writing-guide.md`

**Proposal (Mode 5)**
- [ ] Standalone readable (no live narration required)
- [ ] All sections from the standard structure are present (or intentionally skipped)
- [ ] Pricing matches what was pitched
- [ ] Partnership notes (introductory pricing terms) are clear
- [ ] Prose passes the `/writing-guide.md` edit checklist
- [ ] Client-first framing throughout

**Gamma (Mode 6)**
- [ ] Theme: Mellonhead v3 (themeId defined at the top of SKILL.md)
- [ ] Format matches artifact (presentation for pitch, document for proposal)
- [ ] textMode: preserve
- [ ] Image source set (default: noImages)
- [ ] additionalInstructions includes audience and design constraints
- [ ] Pitch only generated for rehearsal (not for sending before meeting)
- [ ] Proposal only generated after pitch meeting

**Refinement (Mode 7)**
- [ ] Cascading edits applied to all related files
- [ ] Grep verifies no stale references remain
- [ ] Gamma editor prompts provided for targeted slide edits
